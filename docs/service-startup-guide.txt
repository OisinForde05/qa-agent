QA-AGENT SERVICE STARTUP GUIDE
Windows PowerShell | Updated 3 October 2026

Project folder: C:\Users\oisin\Downloads\qa-agent

Use three separate PowerShell terminals, one for each service.
Leave each terminal open while its service is running.
Run the command blocks below in PowerShell, not Command Prompt.

This guide covers the setup discussed so far. The AI service commands
require ai-service/main.py and its Python dependencies from the setup step.
No database, Docker container, or LLM connection is required for these
health endpoints. The Java-to-Python connection is a separate development step.


1. PYTHON AI SERVICE - TERMINAL 1

Set-Location "C:\Users\oisin\Downloads\qa-agent\ai-service"
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000

Check in your browser:
http://localhost:8000/health

Expected response:
{"status":"UP"}

Interactive API documentation:
http://localhost:8000/docs

The health endpoint confirms that this service responds. It does not
confirm an LLM connection or test-generation functionality.


2. JAVA BACKEND - TERMINAL 2

Set-Location "C:\Users\oisin\Downloads\qa-agent\backend"
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\mvnw.cmd spring-boot:run

Check in your browser:
http://localhost:8080/api/health

Expected response:
{"status":"UP"}

The JAVA_HOME path above is the JDK 21 installation you previously showed.
If you update or move the JDK, replace it with the new installation path.
These environment settings apply only to this PowerShell session.

To check Java before starting the backend:
java -version
.\mvnw.cmd -version

Both should report Java 21 for this project setup.


3. REACT FRONTEND - TERMINAL 3

Set-Location "C:\Users\oisin\Downloads\qa-agent\frontend"
npm.cmd run dev

Open the Local URL printed by Vite, normally:
http://localhost:5173

If that port is busy, Vite may print a different port. Use the printed URL.
The backend status should show Connected when the Java backend is running
and the frontend health request and development proxy are configured.
If you started the frontend first, refresh the page after starting Java.


4. STOPPING AND RESTARTING

To stop a service, select its terminal and press Ctrl+C.
If PowerShell asks to terminate a batch job, enter Y.
Stop all three terminals' services when finished.

To restart, run that service's startup command again from its folder.
In a new backend terminal, repeat the JAVA_HOME and Path commands first.
You do not need to reinstall dependencies every time you start a service.


5. FIRST-TIME SETUP OR MISSING DEPENDENCIES

Frontend - if node_modules is missing:

Set-Location "C:\Users\oisin\Downloads\qa-agent\frontend"
npm.cmd install

Python - if .venv is missing, create it and install recorded dependencies:

Set-Location "C:\Users\oisin\Downloads\qa-agent\ai-service"
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

For the initial setup only, if requirements.txt does not yet exist:

.\.venv\Scripts\python.exe -m pip install fastapi uvicorn
.\.venv\Scripts\python.exe -m pip freeze | Set-Content -Encoding utf8 requirements.txt

Calling .venv's python.exe directly means activation is not necessary.
The Java Maven wrapper downloads its dependencies when needed.


6. BUILD CHECKS BEFORE A COMMIT

These checks finish and return to the prompt. They do not start the services.
Stop the Java backend before running its clean build.

Backend (use a terminal configured for JDK 21 as above):

Set-Location "C:\Users\oisin\Downloads\qa-agent\backend"
.\mvnw.cmd clean verify

Frontend:

Set-Location "C:\Users\oisin\Downloads\qa-agent\frontend"
npm.cmd run build
npm.cmd run lint

Python service: start it and check /health returns the expected JSON.
This is a manual smoke check, not an automated test suite.


7. COMMON PROBLEMS

"npm cannot find package.json":
Run npm commands from frontend, not backend or the project root.

"node", "npm.cmd", or "py" is not recognised:
Check that the corresponding runtime is installed, then reopen PowerShell.
Check with node --version, npm.cmd --version, or py --version.

".venv\Scripts\python.exe" cannot be found:
Check that you are in ai-service and have created its virtual environment.

"No module named uvicorn" or "No module named fastapi":
Install requirements using the virtual environment's python.exe as above.

"Could not import module main":
Check that main.py is inside ai-service and that your terminal is there.

"Port already in use" or "Address already in use":
Check whether the service is already running in another terminal.
Stop that instance with Ctrl+C before starting another on the same port.

Frontend shows a backend connection error:
Check http://localhost:8080/api/health directly, check the Java terminal
for errors, then refresh the frontend once the backend is responding.
